Nothing you don’t.

No streaks to protect, no charts to admire, no account to manage. A timer, a gentle sound, and the rest of your attention back.

  • Lives in your menu bar

    One click opens it, a click anywhere else puts it away. The icon fills like a cup as the session runs, and the countdown sits beside the clock on a Mac.

  • Five ways to brew a session

    Espresso 15/3, Classic 25/5, Deep 50/10, Flow 90/20, or your own Custom blend. Rounds and a long break are built in.

  • A chime, not an alarm

    A soft bell, a singing bowl or a wooden block, synthesised as it plays. Focus ends on a lower note than a break, so you know which without looking.

  • A low rumble to sink into

    Optional deep brown noise, like distant surf. Generated live so it never loops, and it fades out by itself when the session ends.

  • Breaks that start themselves

    Focus ends, the break begins. The next focus waits for you unless you ask it not to. Space starts and pauses; Esc puts the window away.

  • Private by design

    No account, no analytics, no network code at all. Your settings live in one small file on your computer and go nowhere else.

Free. Not “free trial”.

A focus timer is some of the simplest software there is, yet most of them want a subscription, an account, or a few euros to unlock the sound you actually like. Lock In has no paid tier to unlock, because there is nothing locked.

It is open source under the GPL, so it stays that way: anyone can read the code, build it themselves, and keep it going.

macOS

macOS 10.15 or later

Apple silicon Intel

Apple silicon is any Mac with an M1 chip or newer. Not sure? Apple menu → About This Mac.

First launch on a Mac

The app isn’t signed with a paid Apple certificate, so macOS may say it is “damaged”. It isn’t. Drag Lock In to Applications, then run this once in Terminal: 

xattr -cr "/Applications/Lock In.app"

Lock In then appears in the menu bar. There is deliberately no Dock icon.

Windows

Windows 10 and 11, 64-bit

Installer (.exe) MSI package
First launch on Windows

SmartScreen doesn’t recognise unsigned apps yet. Choose More info, then Run anyway. Lock In appears in the system tray — look under the ^ arrow and drag it onto the taskbar to keep it in view.

iPhone & Android

Not yet

Phones need real porting work — a phone suspends apps, so the timer has to be rebuilt around that. It’s on the roadmap, and help is welcome.

Questions

Is it really free? What’s the catch?

No catch. There is no paid version, no in-app purchase and no advert. Lock In is a hobby project released under the GPL-3.0 licence, which also guarantees that the code stays open.

Why does my computer warn me when I open it?

Apple and Microsoft charge developers for the certificates that silence those warnings. Lock In costs nothing, so it isn’t signed yet. The app is built in public by GitHub Actions from the code in the repository, and you can build it yourself in about five minutes if you’d rather not take that on trust.

Does it collect any data?

No. The app has no network code at all. Its only outbound action is opening the project page in your browser if you tap the link in Settings. This website has no analytics or cookies either; it only asks GitHub which version is newest.

What is the pomodoro technique?

Work in short, focused sessions — classically 25 minutes — with a short break after each and a longer one after four. Lock In handles the counting and the switching, so all you have to do is start.

Something broke, or I have an idea.

Please open an issue. Bug reports from real machines are the most useful thing anyone can contribute.

Can I help?

Yes! Star the repository, tell a friend who’d like it, report bugs, or send a pull request — the contributing guide explains how to run the app from source.
